01 — Descripción

Gestión deportiva para la comunidad universitaria

Participé en el desarrollo del software enfocado en la gestión de los Centros de Acondicionamiento Físico (CAF) de la Universidad Pedagógica y Tecnológica de Colombia (UPTC). El sistema fue diseñado para la gestión de usuarios y el agendamiento de turnos de los estudiantes en los centros de acondicionamiento físico de la universidad.

La solución buscaba digitalizar y optimizar los procesos de inscripción, control de acceso y programación de actividades físicas, mejorando la experiencia tanto de los estudiantes como de los administradores de los centros deportivos.

02 — Contribuciones

Mis aportes al proyecto

Análisis de requisitos

Analicé y documenté requisitos funcionales y no funcionales para garantizar el correcto diseño y evolución del sistema.

Backend con Spring Boot

Desarrollé el backend del sistema en Java con Spring Boot, implementando el estilo arquitectónico de Microservicios para asegurar modularidad y escalabilidad.

Base de datos MySQL

Estructuré y administré bases de datos en MySQL, optimizando consultas y garantizando la integridad de los datos.

Interfaces en React

Colaboré en la construcción de interfaces gráficas en React, creando una experiencia de usuario fluida y responsiva.

Validación y pruebas

Implementé y validé APIs REST con Postman, y realicé pruebas de rendimiento con Apache JMeter.

Despliegue en AWS Lightsail

Desplegué y configuré la aplicación en AWS Lightsail, asegurando su disponibilidad y rendimiento en producción.

03 — Arquitectura

Sistema basado en microservicios

El sistema fue diseñado bajo una arquitectura de microservicios que permite escalar cada componente de forma independiente y mantener una separación clara de responsabilidades:

  • Microservicios en Spring Boot para modularizar la lógica de negocio del sistema.
  • API REST como interfaz de comunicación entre el frontend y los servicios backend.
  • MySQL para la persistencia estructurada de usuarios, turnos y recursos.
  • React como capa de presentación para una interfaz moderna y responsiva.
  • AWS Lightsail para el despliegue y hospedaje de la aplicación.
