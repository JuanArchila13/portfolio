01 — Description

Management and billing of the water service

I participated in the development of a management and billing system for Acueducto El Tunjo, aimed at optimizing the administration of subscriber user information, automating billing processes, and improving operational efficiency in water service management.

The project made it possible to transform manual processes into automated flows, reducing receipt and report generation times, and facilitating control of the aqueduct's outstanding portfolio.

02 — Contributions

My contributions to the project

Requirements analysis

I analyzed and documented functional and non-functional requirements, ensuring that the solution responded to the aqueduct's operational needs.

Architecture and data

I designed the system architecture and modeled the data structure to ensure a robust, scalable, and easily maintainable solution.

Java development

I contributed to the development of the application in Java, implementing functionalities for user administration, billing generation, and subscriber management.

Receipt optimization

I optimized the billing receipt generation process, achieving a 90% reduction in creation times.

Report automation

I automated the consultation and consolidation of information from users with outstanding balances, achieving an 80% improvement in search and report generation times.

03 — Architecture

Robust and scalable design

The system was designed to support the aqueduct's daily operation with a clear architecture and a well-structured data model:

  • Modular architecture that facilitates system maintenance and evolution.
  • Relational data model designed to ensure referential integrity and consistency of subscriber information.
  • Java application with functionalities focused on users, billing, and reports.
  • Automation of key processes such as receipt generation and outstanding portfolio queries.
